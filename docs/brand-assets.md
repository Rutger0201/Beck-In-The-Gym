# Logo quality: original raster files

The supplied full white PNG is 3840 × 2160 px. Its visible alpha bounds are x=1188..2652 and y=435..1545: the actual lockup occupies about 1464 × 1110 px. The 1280 × 1280 emblem JPG contains about 841 × 645 px of visible white artwork. Both original files already contain irregular, stepped edges; these are visible independently of the website's layout. There is no original BITG vector logo in the inspected repository.

Increasing the canvas size, sharpening, changing the file extension to SVG, or embedding the bitmap in an SVG does not restore smooth original curves. The lasting solution is the original vector source (SVG, AI, EPS or a PDF that actually contains vector paths), or a careful vector redraw of the current mark. Confirm the redrawn geometry and wordmark with the owner before replacing the brand originals. Preserve the uploaded originals as references.

The website currently frames the supplied artwork without modifying it and keeps it at sensible display sizes. No claim is made that the raster source has been repaired or vectorised. Image zoom must remain available for accessibility.
